# RPG Forge Engine

Welcome to **RPG Forge Engine**, a lightweight text-based RPG engine designed to bring interactive storytelling right to your terminal! 

Choose your path, face tough decisions, and experience solo tabletop-style adventures without needing a full group. Stories across various genres will be released continuously over time.

---

## Key Features

- **Multi-Genre Games:** Play through dynamic stories across various genres, delivered directly to your engine.
- **Easy One-Click Setup:** Simple installation process for Windows users.
- **Built-in Updater:** Integrated update system to easily keep your core engine files up to date.
- **Custom Characters:** Select pre-made character profiles or customize your hero's stats and background.
- **Difficulty Modes:** Tailor your adventure difficulty to match your playstyle.
- **Visual Dice & Animations:** Animated dice rolls and interactive terminal displays bring your choices to life.

---

## Installation & Setup

### Windows
1. Download **`Install.bat`**.
2. Double-click **`Install.bat`** to set up the game automatically.
3. Follow the on-screen instructions to start playing!

### Linux & macOS
*Support for Linux and macOS installation scripts is currently in development and will be added in a future update.*

---

## How to Play

1. Run the game launcher/engine.
2. In the Main Menu:
   - Check for core updates (**F**).
   - Select and download a story (**B**).
   - Set up your character and difficulty (**C** / **D**).
   - Start your adventure (**E**)!
